# HookHub

A catalog of community [Claude Code hooks](https://code.claude.com/docs/en/hooks). Hooks show up as cards, each card links to the hook's GitHub repository, and you can filter by the hook event they react to (`PreToolUse`, `Stop`, and so on).

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
```

| Command | What it does |
|---|---|
| `npm test` | unit tests (schema, catalog integrity, filtering) |
| `npm run typecheck` / `npm run lint` | type-check / eslint |
| `npm run build` | production build (also validates the catalog) |
| `npm run refresh:github` | refresh `data/github-meta.json` (set `GITHUB_TOKEN` for a higher rate limit) |

## How it works

The catalog is **curated by hand**: `data/hooks.json`. GitHub topic search is too noisy to use as a source (most results are guides or whole toolkits, not hooks). GitHub is only used to refresh stars, license and last push, and the site never calls it at request time.

- `data/events.json`: the 33 hook events, with exact names from the official docs. When Claude Code adds an event, add it here.
- `data/hooks.json`: one entry per hook, validated by `src/lib/hooks/schema.ts` at build time. A bad entry fails the build.
- `data/github-meta.json`: generated by `scripts/refresh-github.mjs`. Don't edit it by hand.

Filters live in the URL (`/?event=PreToolUse&event=Stop&q=format&sort=name`), so any view can be shared. Selecting several events shows hooks that handle **any** of them.

## Add a hook

1. Read the repository's README and its hook configuration, and note which events it actually registers. Don't guess.
2. Add an entry to `data/hooks.json`:

   ```json
   {
     "slug": "my-hook",
     "name": "My Hook",
     "description": "One sentence, plain text, 200 characters at most.",
     "repo": "owner/name",
     "events": ["PreToolUse"],
     "install": "plugin",
     "tags": ["git"],
     "addedAt": "2026-10-10"
   }
   ```

   `install` is `plugin` (ships a `hooks/hooks.json`), `settings` (copy entries into `settings.json`) or `script` (installed by a script or package).
3. Run `npm run refresh:github && npm test && npm run build`.

## Notes

- Names and descriptions are rendered as plain text, never HTML, so a catalog entry can't inject markup.
- Links go only to `github.com/{owner}/{name}`; the schema rejects anything else.
- Hooks run commands with your permissions. The detail pages tell people to read a hook's code before installing it.
